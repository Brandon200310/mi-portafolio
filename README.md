
# Mi Portafolio - Brandon Molina

Este es mi primer portafolio del curso de
Desarrollo Web Full Stack.

En este proyecto aprendí a crear y organizar
páginas web utilizando HTML.

## Páginas del proyecto

- index.html - Mi presentación personal.
- proyectos.html - Mis proyectos.
- contacto.html - Formulario de contacto.

## Semana 1 - Aprendiendo HTML

### ¿Qué aprendí?
Esta semana aprendí a crear páginas web con HTML,
utilizando títulos, párrafos, imágenes, enlaces,
tablas y formularios.

También aprendí a organizar mejor mi código
y conectar diferentes páginas entre sí.

### Validación
Revisé mis tres páginas con el validador W3C
y todas pasaron sin errores.


### Error que corregí

En mi archivo proyectos.html tenía una tabla
con el atributo border="1".

Lo corregí quitando ese atributo y dejando
solamente la etiqueta <table>.

Aprendí que los bordes y estilos de las tablas
se pueden agregar después utilizando CSS.



### Uso de inteligencia artificial
Utilicé ChatGPT para comprender algunas etiquetas,
resolver dudas y revisar mi código.
Me ayudó a entender mejor cómo funciona HTML.
